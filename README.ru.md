# AWLauncher

[English](README.md) · **Русский**

Самостоятельный лаунчер Armored Warfare для Windows, с консольной версией для Linux и Steam Deck. Он устанавливает, обновляет и запускает игру для аккаунтов **VK Play** (российские серверы) и **FX ID / Wishlist Games** (международные серверы) из одного окна и держит несколько аккаунтов наготове. Это неофициальный фанатский проект; см. [отказ от ответственности](#отказ-от-ответственности).

## Возможности

- **Несколько аккаунтов, два сервиса.** Аккаунты VK Play и FX ID живут рядом: их можно назвать по-своему и запустить любой одним нажатием.
- **Установка и обновление.** Ставит полный клиент в любую папку, докачивает прерванные загрузки, ставит патчи и проверяет каждый скачанный файл. Скачивание и проверку можно поставить на паузу.
- **Одна установка на оба сервиса.** VK Play и основная ветка FX ID используют одну папку игры; перед каждым запуском лаунчер переключает настройки сервиса.
- **Закрытые ветки FX ID.** Активируйте ключ, посмотрите ветки, открытые аккаунту, и выберите, в какую он играет. Ветка ставится рядом с основной папкой и берёт из неё файлы, поэтому скачивается только разница.
- **Проверка и починка файлов.** Перед каждым запуском лаунчер проверяет, что клиент цел, и предлагает скачать только недостающие или повреждённые файлы. Полную проверку всех файлов можно запустить в любой момент.
- **Управление игрой.** Установленные клиенты и их версии, освобождение места от скачанных патчей, удаление закрытой ветки или всей игры.
- **Работает в фоне.** Пока игра ставится, можно переименовывать и удалять аккаунты, добавлять новые и управлять ветками других аккаунтов.
- **Не мешает.** После запуска игры лаунчер уходит в область уведомлений. Он умеет закрыть запущенную игру, запускаться вместе с Windows и обновлять сам себя.
- **Русский и английский.** Окно говорит на языке Windows или на том, который вы выберете.

## Требования

- Windows 10 или 11, 64-бит. На Linux консольная версия работает в любом 64-битном дистрибутиве; см. [Linux и Steam Deck](#linux-и-steam-deck).
- Microsoft Edge WebView2 Runtime. Он входит в Windows 11 и актуальную Windows 10; если его нет, лаунчер предложит страницу загрузки.
- Около 70 ГиБ свободного места для новой установки.

## Начало работы

1. Скачайте `AWLauncher-Setup.exe` из [последнего релиза](../../releases/latest) и запустите. Установщик ставит лаунчер для вашего пользователя Windows в `%LOCALAPPDATA%\Programs\AWLauncher` без прав администратора и добавляет его в меню «Пуск» и, если хотите, на рабочий стол. Удаляется он как любое приложение, в **Параметры → Приложения → Установленные приложения**. При первом запуске Windows может предупредить о неизвестном издателе; выберите **Подробнее → Выполнить в любом случае**.

   Можно обойтись без установщика: скачайте `AWLauncher.exe` из того же релиза и положите в любую папку. Оба варианта хранят данные в одном месте и одинаково обновляются.
2. Запустите AWLauncher и нажмите **+**, чтобы добавить аккаунт:
   - **VK Play**: страница входа откроется в браузере. Если вы уже вошли там в VK Play, она сама вернётся в лаунчер.
   - **FX ID**: введите e-mail, затем 6-значный код из письма: наберите его или вставьте через Ctrl+V, и он отправится сразу после последней цифры.
3. Выберите аккаунт и нажмите **Играть**.
4. При первом запуске лаунчер ищет уже установленную игру. Если не найдёт, выберите папку: существующая установка используется как есть, а в пустую папку игра ставится заново. В окне видно свободное место на диске.
5. Лаунчер ставит обновления, если они есть, проверяет файлы и запускает игру.

## Как пользоваться

**Аккаунты.** Дважды щёлкните аккаунт или нажмите его кнопку ▶, чтобы играть. В меню ⋮ есть **Сделать основным** (закрепляет аккаунт за кнопкой **Играть** и меню в трее, не запуская игру), **Переименовать** и **Удалить**, а у аккаунтов FX ID ещё **Ветки клиента** и **Активировать ключ**. Фильтр вверху боковой панели показывает все аккаунты или только один сервис.

**Ветки.** **Активировать ключ** добавляет аккаунту FX ID закрытую ветку (например, супертест). **Ветки клиента** показывает ветки, открытые аккаунту, с версией и размером и позволяет выбрать, в какую он играет.

**Прогресс и логи.** Полоса прогресса показывает скачивание и проверки со скоростью и оставшимся временем. **Пауза** приостанавливает скачивание или проверку файлов, **Продолжить** возобновляет с того же места; замену файлов игры во время установки патча приостановить нельзя. **Логи** хранят весь вывод, его можно скопировать.

**Игра.** Основная папка игры, установленные клиенты (VK Play, основная ветка FX ID и закрытые ветки) с версиями и место, занятое скачанными патчами. Доступные вашим аккаунтам клиенты и ветки можно скачать кнопкой **Скачать**, не запуская игру. **Проверить файлы** сравнивает каждый файл клиента с официальным списком и скачивает отличающиеся; для FX ID нужен аккаунт FX ID. **Удалить** у патчей удаляет скачанные патчи, **Удалить** у ветки удаляет закрытую ветку, а **Удалить игру** удаляет игру и её ветки. Файлы, которые ставил не лаунчер (например, скриншоты), остаются, если вы не согласитесь удалить всю папку.

**Настройки.** Откройте папку данных лаунчера, выберите, запускается ли AWLauncher вместе с Windows (**Выкл.**, **Окно** или **Трей** — в область уведомлений), тему, цвет и язык: **Авто** следует языку Windows (русский для русской Windows, иначе английский), или выберите **English** либо **Русский**. Язык действует на окно и меню в трее; логи остаются на английском. **Версия** показывает версию лаунчера; **Проверить обновления** ищет новый [релиз](../../releases) на GitHub. Лаунчер и сам проверяет обновления при запуске и отмечает **Настройки** точкой, когда выходит новая версия. **Обновить** скачивает новый `AWLauncher.exe` (и `AWLauncherConsole.exe`, если он лежит рядом), проверяет его, ставит на место старого и перезапускается; аккаунты и настройки сохраняются. Если лаунчер не может писать в свою папку, он предлагает страницу релиза.

**Во время игры.** После запуска игры лаунчер уходит в область уведомлений. Щелчок по значку открывает его, повторный щелчок прячет; по правому щелчку можно запустить основной аккаунт, отмеченный булавкой (например, **Играть Tanker · VK Play**), а также **Открыть AWLauncher** и **Выход**. Закрытие окна тоже прячет лаунчер. Пока игра запущена, **Закрыть игру** просит её закрыться и завершает через 10 секунд.

**Несколько дел сразу.** Установка, обновление или запуск идут по одному. В это время можно переименовать любой аккаунт, а также добавлять, удалять и настраивать ветки других аккаунтов. Если две задачи спрашивают что-то одновременно, их окна ждут друг друга, и в каждом написано, какая задача спрашивает.

Одновременно работает только одна копия лаунчера; при запуске второй открытое окно выходит на передний план.

### Консольная версия

`AWLauncherConsole.exe` умеет то же самое в виде текстового меню, для скриптов и поиска проблем. Меню консоли на английском:

| Ввод | Действие |
| --- | --- |
| Enter | играть последним аккаунтом |
| `N` | играть аккаунтом номер N |
| `+` | добавить аккаунт |
| `-N` | удалить аккаунт N |
| `r [N]` | переименовать аккаунт |
| `b [N]` | показать ветки FX ID и выбрать одну |
| `k [N]` | активировать ключ FX ID |
| `g` | игра: проверка файлов, удаление скачанных патчей, удаление ветки, удаление игры |
| `x` | закрыть запущенную игру |
| `q` | выход |

`AWLauncherConsole.exe play [АККАУНТ]` ничего не спрашивает: ставит обновления, чинит файлы, запускает игру за АККАУНТ (номер из меню, имя или логин; без него — последний аккаунт) и ждёт, пока игра закроется. Новую установку и вход в аккаунт он никогда не начинает — их делают в меню. `AWLauncherConsole.exe version` печатает версию.

### Linux и Steam Deck

На Linux есть только консольная версия: `awlauncher-linux-amd64` из [последнего релиза](../../releases/latest). Сам лаунчер работает нативно, а игра, как программа для Windows, запускается через [umu-launcher](https://github.com/Open-Wine-Components/umu-launcher) (Proton вне Steam) или, если его нет, через Wine. Работает ли игра под Proton, зависит от самой игры; лаунчер только запускает её.

1. Установите umu-launcher, как описано в его README, чтобы `umu-run` был в `PATH`. В SteamOS система доступна только для чтения, поэтому на Steam Deck берите сборку, которая ставится в домашнюю папку, например zipapp из релизов umu-launcher, распакованный в `~/.local/bin`.
2. Сделайте файл исполняемым и запустите в терминале:
   ```bash
   chmod +x awlauncher-linux-amd64 && ./awlauncher-linux-amd64
   ```
   Добавьте аккаунты и установите игру или выберите существующую папку, как в меню выше. Вход в VK Play открывается в браузере по умолчанию.
3. Для игрового режима добавьте файл в Steam как стороннюю игру и укажите в параметрах запуска `play` (или `play АККАУНТ`). Тогда Steam показывает игру запущенной, пока она не закроется. Обновления ставятся перед запуском без окна, поэтому большие обновления лучше ставить заранее в режиме рабочего стола.

Подробности:

- Данные лежат в `~/.local/share/awlauncher` (или в `$XDG_DATA_HOME/awlauncher`). Сохранённые входы — это файлы, доступные только вашему пользователю; DPAPI в Linux нет.
- Префикс Wine — `~/.local/share/awlauncher/prefix`, если не задан `WINEPREFIX`. Версию Proton выбирает umu-launcher; задайте `PROTONPATH=GE-Proton`, чтобы использовать последний GE-Proton. Вывод Proton или Wine пишется в `~/.local/share/awlauncher/game.log`.
- `AWLAUNCHER_RUNNER` заменяет способ запуска, например `AWLAUNCHER_RUNNER="umu-run"` или путь к `wine`.
- Файловые системы Linux различают `Bin64` и `bin64`; лаунчер сохраняет регистр уже лежащих файлов, чтобы патчи, сделанные под Windows, попадали в нужные файлы.

## Где хранятся данные

Всё лежит в `%LOCALAPPDATA%\AWLauncher`:

- `config.json`: основная папка игры и список аккаунтов, без паролей и токенов;
- `accounts\*.bin`: сохранённый вход каждого аккаунта, зашифрованный Windows DPAPI, так что прочитать его может только ваш пользователь Windows;
- `ui.json`: тема, цвет и язык; `WebView2`: данные браузера окна.

В папке игры лаунчер хранит своё состояние и скачанные патчи в `-gup-`. Собственный `user.cfg` каждого сервиса, в том виде, в каком он приходит из файлов сервиса, хранится в `-gup-\awlauncher` и ставится на место перед запуском игры; у закрытых веток свои папки со своими `user.cfg`. При удалении аккаунта удаляется его сохранённый вход; файлы игры остаются.

## Решение проблем

- **Вход в VK Play не возвращается в лаунчер.** Если браузер спрашивает, можно ли vkplay.ru обращаться к приложениям на этом устройстве, разрешите. Иначе нажмите **Войти здесь** на карточке входа: вход откроется в собственном окне лаунчера и не зависит от браузера. **Другой аккаунт** входит под другим аккаунтом VK Play.
- **«Local port 51200 is busy».** Запущен другой лаунчер VK Play. Закройте его и попробуйте снова.
- **Игра не запускается или вылетает.** На странице **Игра** нажмите **Проверить файлы** у её клиента: каждый файл будет проверен, а повреждённые скачаются заново. Что произошло, видно в **Логах**.

## Отказ от ответственности

AWLauncher — неофициальный фанатский проект. Его не делают, не одобряют и не поддерживают VK, MY.GAMES, Wishlist Games и создатели Armored Warfare. Armored Warfare, VK Play, FX ID и другие названия принадлежат их владельцам и упоминаются здесь только затем, чтобы сказать, с чем работает лаунчер. В лаунчере нет их файлов и логотипов.

Лаунчер входит в VK Play и FX ID так же, как их собственные лаунчеры, и меняет файлы настроек игры, чтобы переключаться между сервисами. Правила этих сервисов могут не разрешать сторонние лаунчеры, и за его использование аккаунт могут ограничить. Вы пользуетесь AWLauncher на свой риск; он предоставляется как есть, без каких-либо гарантий.

Лаунчер никогда не видит и не хранит ваши пароли: вход в VK Play происходит на странице VK Play, а FX ID использует код из письма. Сохранённые входы остаются на вашем компьютере и отправляются только тому сервису, которому принадлежат. Кроме самих сервисов и их серверов загрузки, лаунчер обращается только к GitHub, чтобы проверить обновления.

Если вы представляете одну из этих компаний и у вас есть вопросы, откройте issue — с ним разберутся быстро.

## Сборка

Go 1.26.6 или новее нужен только для сборки лаунчера.

```powershell
go build -ldflags '-H=windowsgui' -o AWLauncher.exe ./cmd/awlauncher
```

Такая сборка считает себя сборкой для разработки и сама не обновляется. Чтобы задать ей версию, добавьте в `-ldflags` `-X github.com/TheGreatPepix/awlauncher/internal/launcher.Version=v1.2.3`; GitHub Actions делает это с выводом `git describe --tags`.

```powershell
go build -o AWLauncherConsole.exe ./cmd/awlauncher-console
```

```powershell
go test ./...
```

GitHub Actions собирает и тестирует оба exe при каждом push и pull request, собирает установщик из `installer/awlauncher.iss` с помощью [Inno Setup 6](https://jrsoftware.org/isinfo.php) и прикладывает все три файла к запуску. Чтобы собрать установщик самому, положите оба exe в `dist` и выполните `ISCC.exe -DAppVersion=1.2.3 -DFileVersion=1.2.3.0 installer\awlauncher.iss`. Push тега вроде `v1.0.0` или публикация релиза для нового тега прикладывает файлы к этому релизу. Лаунчер сравнивает свою версию с последним релизом, поэтому теги должны выглядеть как `v1.2.3`; тег с суффиксом, например `v1.2.3-rc1`, никогда не предлагается как обновление.

Окно — это веб-страница в WebView2; её файлы лежат в `internal/launcher/ui` и встраиваются в exe. Если открыть `index.html` в обычном браузере, запустится демо с примерами аккаунтов — удобно для работы над дизайном. Задайте `AWLAUNCHER_DEVTOOLS=1`, чтобы получить инструменты разработчика в окне лаунчера. Значок — файл `internal/appicon/awlauncher.ico`; окно, его боковая панель и трей используют его как есть, и больше нигде значок не рисуется. Чтобы сменить значок, замените этот файл (размеры от 16 до 256 px) и выполните `go generate ./cmd/...`, что заодно встроит его в exe; то же самое нужно после изменения манифеста приложения.

Лаунчер использует [bodgit/sevenzip](https://github.com/bodgit/sevenzip), [go-deltasync/vcdiff](https://github.com/go-deltasync/vcdiff), [jchv/go-webview2](https://github.com/jchv/go-webview2) и [fyne.io/systray](https://github.com/fyne-io/systray). Шрифт интерфейса — Rubik, под лицензией SIL Open Font License.
