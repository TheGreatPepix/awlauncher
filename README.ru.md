# AWLauncher

[English](README.md) · **Русский**

Самостоятельный лаунчер Armored Warfare для Windows. Он устанавливает, обновляет и запускает игру для аккаунтов **VK Play** (российские серверы) и **FX ID / Wishlist Games** (международные серверы) из одного окна и держит несколько аккаунтов наготове. Это неофициальный фанатский проект; см. [отказ от ответственности](#отказ-от-ответственности).

## Возможности

- **Несколько аккаунтов, два сервиса.** Аккаунты VK Play и FX ID живут рядом: их можно назвать по-своему и запустить любой одним нажатием.
- **Установка и обновление.** Ставит полный клиент в любую папку, докачивает прерванные загрузки, ставит патчи и проверяет каждый скачанный файл. Скачивание и проверку можно поставить на паузу.
- **Одна установка на оба сервиса.** VK Play и основная ветка FX ID используют одну папку игры; перед каждым запуском лаунчер переключает настройки сервиса.
- **Закрытые ветки FX ID.** Активируйте ключ, посмотрите ветки, открытые аккаунту, и выберите, в какую он играет. Ветка ставится рядом с папкой FX ID и берёт из неё файлы, поэтому скачивается только разница.
- **Проверка и починка файлов.** Перед каждым запуском лаунчер проверяет, что клиент цел, и предлагает скачать только недостающие или повреждённые файлы. Полную проверку всех файлов можно запустить в любой момент.
- **Управление игрой.** Установленные клиенты и их версии, освобождение места от скачанных патчей, удаление клиента или закрытой ветки.
- **Работает в фоне.** Пока игра ставится, можно переименовывать и удалять аккаунты, добавлять новые и управлять ветками других аккаунтов.
- **Не мешает.** После запуска игры лаунчер уходит в область уведомлений. Он умеет закрыть запущенную игру, запускаться вместе с Windows и обновлять сам себя.
- **Русский и английский.** Окно говорит на языке Windows или на том, который вы выберете.

## Требования

- Windows 10 или 11, 64-бит.
- Linux и Steam Deck (x86-64): `AWLauncher-x86_64.AppImage`. Игра запускается через Proton, поэтому нужен Steam с любым Proton, GE-Proton, umu-launcher (есть у Lutris и Heroic) или Wine; см. [Linux и Steam Deck](#linux-и-steam-deck).
- Около 70 ГиБ свободного места для новой установки.

## Начало работы

1. Скачайте `AWLauncher-Setup.exe` из [последнего релиза](../../releases/latest) и запустите. Установщик ставит лаунчер для вашего пользователя Windows в `%LOCALAPPDATA%\Programs\AWLauncher` без прав администратора и добавляет его в меню «Пуск» и, если хотите, на рабочий стол. Удаляется он как любое приложение, в **Параметры → Приложения → Установленные приложения**. При первом запуске Windows может предупредить о неизвестном издателе; выберите **Подробнее → Выполнить в любом случае**.

   Можно обойтись без установщика: скачайте `AWLauncher-portable.zip` из того же релиза и распакуйте в отдельную папку. Оба варианта хранят данные в одном месте. Переносная копия тоже обновляется через установщик в ту же папку и после этого появляется в **Установленных приложениях**.

   AWLauncher 0.5 сам обновляется до этой версии: его кнопка **Обновить** скачивает из релиза `AWLauncher.exe`, который ставит новый лаунчер в папку старого и запускает его. Если лаунчер 0.5 лежал на рабочем столе или в «Загрузках», новый ставится в `%LOCALAPPDATA%\Programs\AWLauncher`.
2. Запустите AWLauncher и нажмите **Добавить аккаунт**:
   - **VK Play**: страница входа откроется в браузере. Если вы уже вошли там в VK Play, она сама вернётся в лаунчер.
   - **FX ID**: введите e-mail, затем 6-значный код из письма: наберите его или вставьте через Ctrl+V, и он отправится сразу после последней цифры.
3. Выберите аккаунт и нажмите **Играть**.
4. При первом запуске лаунчер ищет уже установленную игру. Если не найдёт, выберите папку на странице **Игра** или при первом скачивании или запуске: существующая установка используется как есть, а в пустую папку игра ставится заново. Предлагаемый путь — `C:\Games\Armored Warfare`; его можно изменить. В окне видно свободное место на диске.
5. Лаунчер ставит обновления, если они есть, проверяет файлы и запускает игру.

## Как пользоваться

**Аккаунты.** Дважды щёлкните аккаунт или нажмите его кнопку ▶, чтобы играть. В меню ⋮ есть **Сделать основным** (закрепляет аккаунт за кнопкой **Играть** и меню в трее, не запуская игру), **Переименовать** и **Удалить**, а у аккаунтов FX ID ещё **Ветки клиента** и **Активировать ключ**.

**Ветки.** **Активировать ключ** добавляет аккаунту FX ID закрытую ветку (например, супертест). **Ветки клиента** показывает ветки, открытые аккаунту, с версией и размером и позволяет выбрать, в какую он играет.

**Прогресс и логи.** Полоса прогресса показывает скачивание и проверки со скоростью и оставшимся временем. **Пауза** приостанавливает скачивание или проверку файлов, **Продолжить** возобновляет с того же места; замену файлов игры во время установки патча приостановить нельзя. **Логи** хранят весь вывод, его можно скопировать.

**Игра.** В разделе **Клиенты** есть клиент для каждого сервиса, на котором у вас есть аккаунт: VK Play для аккаунтов VK Play, основная ветка и закрытые ветки FX ID для аккаунтов FX ID; установленный клиент остаётся в списке и без аккаунта, чтобы его можно было удалить. У клиента показаны версия и папка. У неустановленного клиента есть кнопка **Скачать**, у установленного — **Проверить файлы**: она восстанавливает файлы, отличающиеся от официального списка, даже когда моды разрешены (для FX ID нужен аккаунт FX ID). В меню **⋮** лежат **Проверить обновления** (ищет новые патчи или новую версию ветки и предлагает их поставить), **Открыть папку**, **Сменить папку…** и **Удалить клиент**, который удаляет папку установки; закрытые ветки в соседних папках остаются. У VK Play и FX ID своя папка у каждого; закрытая ветка ставится рядом с клиентом FX ID, если не выбрать другую папку. **Разрешить моды** сохраняет существующие изменённые файлы при обычном запуске, но отсутствующие файлы по-прежнему скачиваются; обновления игры могут заменить изменённые файлы. **Скачанные патчи** показывают занятое место, кнопка **Удалить** их удаляет. Файлы, которые ставил не лаунчер (например, скриншоты), остаются, если вы не согласитесь удалить всю папку.

Для VK Play пункт **Проверить обновления** предложит предзагрузить патч, если его торрент уже выложен, а новый билд ещё не появился в каталоге. Согласиться на скачивание можно и во время игры. Файлы остаются в кэше; установка начнётся только после публикации билда и проверки подписей из каталога.

**Настройки.** Откройте папку данных лаунчера, выберите, запускается ли AWLauncher вместе с Windows (**Выкл.**, **Окно** или **Трей** — в область уведомлений), тему, цвет и язык: **Авто** следует языку Windows (русский для русской Windows, иначе английский), или выберите **English** либо **Русский**. Язык действует на окно и меню в трее; логи остаются на английском. **Версия** показывает версию лаунчера; **Проверить обновления** ищет новый [релиз](../../releases) на GitHub. Лаунчер и сам проверяет обновления при запуске и отмечает **Настройки** точкой, когда выходит новая версия. **Обновить** скачивает новый `AWLauncher-Setup.exe`, проверяет его, закрывает лаунчер и даёт установщику заменить его; установщик сам запускает новую версию. Аккаунты и настройки сохраняются.

**Во время игры.** После запуска игры лаунчер уходит в область уведомлений. Щелчок по значку открывает его, повторный щелчок прячет; по правому щелчку можно запустить основной аккаунт, отмеченный булавкой (например, **Играть Tanker · VK Play**), а также **Открыть AWLauncher** и **Выход**. Закрытие окна тоже прячет лаунчер. Пока игра запущена, **Закрыть игру** просит её закрыться и завершает через 10 секунд.

**Несколько дел сразу.** Установка, обновление или запуск идут по одному. В это время можно переименовать любой аккаунт, а также добавлять, удалять и настраивать ветки других аккаунтов. Если две задачи спрашивают что-то одновременно, их окна ждут друг друга, и в каждом написано, какая задача спрашивает.

Одновременно работает только одна копия лаунчера; при запуске второй открытое окно выходит на передний план.

## Linux и Steam Deck

Скачайте `AWLauncher-x86_64.AppImage`, сделайте файл исполняемым и запустите. На Steam Deck это делается в режиме рабочего стола; затем щёлкните по файлу правой кнопкой и выберите «Add to Steam», чтобы запускать лаунчер из игрового режима, где он открывается на весь экран.

Лаунчер сам запускает Windows-версию игры в своём префиксе Wine `~/.local/share/awlauncher/prefix`. Если установлен umu-launcher (в `PATH` или от Lutris или Heroic), игра идёт через него, иначе через Proton из Steam в Steam Linux Runtime, как это делает сам Steam. Сначала выбирается самый новый GE-Proton, затем самый новый Proton от Valve; другой можно выбрать в «Настройки → Proton». Если на Steam Deck ещё ни одна игра не использовала Proton, установите его в Steam (Библиотека → Инструменты → Proton). `AWLAUNCHER_RUNNER` задаёт команду вручную, а вывод игры пишется в `~/.local/share/awlauncher/game.log`.

Вход в VK Play открывает браузер, поэтому его удобнее делать в режиме рабочего стола; FX ID входит по коду из письма где угодно. Сессии хранятся в `~/.local/share/awlauncher/accounts`, их может прочитать только ваш пользователь; если системное хранилище паролей (KWallet или GNOME Keyring) открыто, они шифруются ключом из него. Если хранилища нет или оно заблокировано, как бывает в игровом режиме, сессия сохраняется без шифрования, а зашифрованная раньше попросит войти заново, пока хранилище не откроется.

## Где хранятся данные

Всё лежит в `%LOCALAPPDATA%\AWLauncher`:

- `config.json`: основная папка игры и список аккаунтов, без паролей и токенов;
- `accounts\*.bin`: сохранённый вход каждого аккаунта, зашифрованный Windows DPAPI, так что прочитать его может только ваш пользователь Windows;
- `ui.json`: тема, цвет и язык. Папка `WebView2` осталась от версий до 1.0, её можно удалить.

В папке игры лаунчер хранит своё состояние и скачанные патчи в `-gup-`. Собственный `user.cfg` каждого сервиса, в том виде, в каком он приходит из файлов сервиса, хранится в `-gup-\awlauncher` и ставится на место перед запуском игры; у закрытых веток свои папки со своими `user.cfg`. При удалении аккаунта удаляется его сохранённый вход; файлы игры остаются.

## Решение проблем

- **Вход в VK Play не возвращается в лаунчер.** Если браузер спрашивает, можно ли vkplay.ru обращаться к приложениям на этом устройстве, разрешите. Иначе нажмите **Войти здесь** на карточке входа: вход откроется в собственном окне лаунчера и не зависит от браузера. **Другой аккаунт** входит под другим аккаунтом VK Play.
- **«Local port 51200 is busy».** Запущен другой лаунчер VK Play. Закройте его и попробуйте снова.
- **Игра не запускается или вылетает.** На странице **Игра** нажмите **Проверить файлы** у её клиента: каждый файл будет проверен, а повреждённые скачаются заново. Что произошло, видно в **Логах**.

## Отказ от ответственности

AWLauncher — неофициальный фанатский проект. Его не делают, не одобряют и не поддерживают VK, MY.GAMES, Wishlist Games и создатели Armored Warfare. Armored Warfare, VK Play, FX ID и другие названия принадлежат их владельцам и упоминаются здесь только затем, чтобы сказать, с чем работает лаунчер. В лаунчере нет их файлов и логотипов.

Лаунчер входит в VK Play и FX ID так же, как их собственные лаунчеры, и меняет файлы настроек игры, чтобы переключаться между сервисами. Правила этих сервисов могут не разрешать сторонние лаунчеры, и за его использование аккаунт могут ограничить. Вы пользуетесь AWLauncher на свой риск; он предоставляется как есть, без каких-либо гарантий.

Лаунчер никогда не видит и не хранит ваши пароли: вход в VK Play происходит на странице VK Play, а FX ID использует код из письма. Сохранённые входы остаются на вашем компьютере и отправляются только тому сервису, которому принадлежат. Кроме самих сервисов и их серверов загрузки, лаунчер обращается только к GitHub, чтобы проверить обновления.

Если вы представляете одну из этих компаний и у вас есть вопросы, откройте issue — с ним разберутся быстро.

## Сборка

Лаунчер — это окно на Flutter (`app`) и ядро на Go `awcore.exe` рядом с ним; окно запускает ядро и общается с ним строками JSON. Для сборки нужны Go 1.26.6 или новее и Flutter 3.47.7.

```powershell
go build -ldflags '-H=windowsgui' -o awcore.exe ./cmd/awcore
cd app
flutter build windows --release
copy ..\awcore.exe build\windows\x64\runner\Release\
```

`flutter run -d windows` запускает окно с тем `awcore.exe`, который указан в `AWCORE`; с `--dart-define=AWLAUNCHER_DEMO=true` окно работает на примерах аккаунтов без ядра.

Такая сборка считает себя сборкой для разработки и сама не обновляется. Чтобы задать ей версию, добавьте в `-ldflags` `-X github.com/TheGreatPepix/awlauncher/internal/launcher.Version=v1.2.3`; GitHub Actions делает это с выводом `git describe --tags`.

```powershell
go test ./...
cd app; $env:AWCORE = "..\awcore.exe"; flutter test
```

GitHub Actions собирает и тестирует лаунчер при каждом push и pull request, дополнительно гоняет тесты на Linux, чтобы ядро оставалось переносимым, и собирает файлы релиза: окно на Flutter с `awcore.exe` папкой и архивом `AWLauncher-portable.zip`, установщик `AWLauncher-Setup.exe` из `installer/awlauncher.iss` с помощью [Inno Setup 6](https://jrsoftware.org/isinfo.php) и `AWLauncher.exe` из `cmd/awbridge`, который несёт в себе установщик и переводит AWLauncher 0.5 на эту версию. Чтобы собрать установщик самому, положите папку из `flutter build windows` вместе с `awcore.exe` в `dist\app` и выполните `ISCC.exe -DAppVersion=1.2.3 -DFileVersion=1.2.3.0 installer\awlauncher.iss`. Push тега вроде `v1.0.0` или публикация релиза для нового тега прикладывает три файла к этому релизу. Лаунчер сравнивает свою версию с последним релизом, поэтому теги должны выглядеть как `v1.2.3`; тег с суффиксом, например `v1.2.3-rc1`, никогда не предлагается как обновление.

Значок лежит в двух файлах: `app/windows/runner/resources/app_icon.ico` для окна и трея и `installer/awlauncher.ico` для установщика и, через `go generate ./cmd/awbridge`, для переходного exe.

Ядро использует [bodgit/sevenzip](https://github.com/bodgit/sevenzip) и [go-deltasync/vcdiff](https://github.com/go-deltasync/vcdiff); окно — [Flutter](https://flutter.dev) и [file_selector](https://pub.dev/packages/file_selector). Шрифт интерфейса — Roboto Flex, под лицензией SIL Open Font License.
